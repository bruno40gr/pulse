# Bundled fonts

Baloo2-variable.ttf is the upstream Baloo 2 variable font from Google Fonts:
https://github.com/google/fonts/tree/main/ofl/baloo2

Copyright and SIL Open Font License are preserved in OFL-Baloo2.txt.
It is loaded through next/font/local, preserving --font-baloo-2 while removing
the build-time Google Fonts CSS dependency that failed in deployment 676ecb0.
